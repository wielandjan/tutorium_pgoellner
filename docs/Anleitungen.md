Erstellen der Umgebungsvariable JAVA_HOME

1. Öffne das Windows-Startmenü (drücke die Windows-Taste) und
tippe Umgebungsvariablen (bzw. Environment Variables) ein

2. Klicke auf den Knopf Umgebungsvariablen... bzw. Environment Variables...

3.

Erstelle eine neue Variable unter System Variablen bzw. System variables

4. Wähle JAVA_HOME für den Namen und für den Wert den Pfad zur aktuellen Java-Installation;

normalerweise sollte das C:\Program Files\Java\jdk-25 sein
Schließe mit OK ab
